# Inter Font Setup

Unduh Inter font (weight 400, 500, 600, 700) dari:
https://fonts.google.com/specimen/Inter

atau

https://github.com/rsms/inter/releases

Letakkan file .ttf di folder ini:
- assets/fonts/inter/Inter-Regular.ttf   (weight 400)
- assets/fonts/inter/Inter-Medium.ttf    (weight 500)
- assets/fonts/inter/Inter-SemiBold.ttf  (weight 600)
- assets/fonts/inter/Inter-Bold.ttf      (weight 700)

Setelah meletakkan file, jalankan: flutter pub get
